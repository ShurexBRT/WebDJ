# WebDJ implementation roadmap

## Completed

- Studio UI redesign
- BPM analysis, pitch and tempo sync
- Beat grid, downbeat offset and quantize
- Master deck, phase sync and beat nudge
- Session and track-profile persistence
- Processed master-mix recording

## Active

1. Local music library and metadata
2. Musical key detection and Camelot mapping
3. Harmonic-mixing compatibility guidance
4. Beat-synchronised effects
5. Master limiter, clip protection and auto-gain
6. Keyboard shortcuts and Web MIDI control
7. PWA installation and offline shell
8. Optional online music-source adapters

## Removed from scope

- Sampler and sample-bank development

The project remains a personal browser DJ playground. New work should prioritise mixing reliability, analysis quality and controller usability over decorative or rarely used features.
